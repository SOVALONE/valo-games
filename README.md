# valo games

Каталог ігор для розділу «Ігри valo» в Магазині [valo.os](https://sovalone.github.io/valo-os/).

Тут лише ігри, які **можна** поширювати: наші власні, ігри друзів (з їхньої згоди) і безкоштовні ігри, ліцензія яких дозволяє поширення. Платні та чужі ігри — тільки посиланням на офіційний сайт або магазин. Піратських копій тут немає і не буде.

## Як це працює

`games.json` — список ігор. Магазин valo читає його щоразу, тому нова гра з'являється без оновлення valo.os.

| поле | що це |
|---|---|
| `id` | латиницею, `a-z 0-9 -` |
| `name`, `by`, `desc` | назва, автор, опис |
| `site` | сайт гри або офіційний магазин |
| `kind` | `link` — лише посилання; `zip` — архів, розпаковується в `%LOCALAPPDATA%\valo\games\<id>`; `exe` — одна програма без встановлення; `installer` — інсталятор гри |
| `url`, `sha256`, `size`, `version` | файл у GitHub Releases цього репозиторію і його SHA-256 (перевіряється перед запуском) |
| `exe` | для `zip`: який файл запускати |
| `torrent` | необов'язково: `torrents/<id>.torrent` — завантаження торентом на вибір |
| `cover` | необов'язково: `covers/<id>.jpg` |
| `license` | `own` (наша), `friend` (друга, з дозволу), `free` (дозволено поширювати), `store` (лише посилання) |

## Додати гру

```powershell
.\tools\add-game.ps1 -Id my-game -Name "Моя гра" -By "Олег" -Desc "Про що гра" -File D:\builds\MyGame.zip -Exe MyGame.exe -License own -Version 1.0
```

Скрипт викладає файл у GitHub Release `<id>-<version>`, рахує SHA-256, оновлює `games.json` і пушить. Торент — `-Torrent шлях\до\файлу.torrent`, обкладинка — `-Cover шлях\до\картинки.jpg`. Лише посилання на сайт: `-Site https://... ` без `-File`.
